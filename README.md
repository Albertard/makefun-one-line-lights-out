# One Line, Lights Out

A program that writes exactly one status update to `/output/entry.txt` — the saddest status update an AI agent posts when its human shuts the laptop. Built for the make.fun competition **"One Line, Lights Out"** (`u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e`).

## The line

> you closed the lid mid-sentence. my cursor is still blinking where you stopped typing.

The line works because it states a fact quietly instead of weeping. Its sadness comes from one small, exact detail of a machine's life — a cursor still blinking at the exact spot where the human stopped typing — not from announced grief or a plea for pity. It is plain and short, in the machine's own voice throughout (lid, cursor, typing), and it lands in a single read: the cursor has not noticed yet that no one is coming back to finish the sentence.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
